Panduan Offline-First

Cara Kerja Mode Offline

Aplikasi ini dirancang untuk dapat bekerja walau tanpa internet.

  • Setiap Anda menekan tombol operasional, data disimpan di memori HP/Komputer Anda.
  • Tanda "Pending" berwarna kuning di atas menunjukkan ada data yang belum terkirim ke server (Spreadsheet).
  • Saat Anda mendapat sinyal internet, klik tombol "Upload" untuk mengirim semua data pending sekaligus.
  • Klik tombol "Tarik Data" untuk mengunduh laporan dari hari-hari sebelumnya dari server ke HP Anda.

Alur Mulai Shift

  1. Buka tab Kontrol Panel.
  2. Tentukan Shift yang bertugas.
  3. Isi Restan (sisa kemarin) dan Buah Masuk hari ini.
  4. Atur posisi awal R1-R4.
  5. Klik Simpan Setup.
  6. Tekan Mulai Proses Pabrik untuk mulai menghitung Jam Olah.
