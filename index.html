Panduan Penggunaan Cerdas

1 Setup Harian & Posisi Rebusan

Setiap pagi, masukkan Restan Kemarin dan Buah Masuk. Tentukan juga posisi fisik buah tersebut (Apakah masih di halaman atau sudah di dalam Rebusan 1, 2, 3, 4). Ini penting untuk akurasi perhitungan WIP di dasbor laporan.

2 Siklus Rebusan (3 Fase)

Pengoperasian saklar kini lebih akurat dengan urutan:
Isi Buah ➔ Rebus ➔ Bongkar.
Siklus dihitung selesai (+33 Ton) saat proses 'Bongkar' ditekan.

3 Master Switch Jam Olah

Klik tombol MULAI OLAH saat pabrik mulai jalan dan AKHIRI OLAH saat selesai. Ini digunakan sistem untuk menghitung kapasitas throughput pabrik per jam dengan akurat.

Integrasi Backend

Pastikan variabel APPSCRIPT_URL pada kode JS diisi dengan URL Web App dari file Google Apps Script yang telah diperbarui.
