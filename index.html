Panduan Penggunaan Aplikasi

1. Kontrol Panel

Halaman utama untuk mengontrol peralatan. Tekan tombol 'Buka' untuk menyalakan dan 'Tutup' untuk memadamkan. Status lampu di sebelah nama alat akan berubah sesuai kondisi.

2. Kegiatan

Gunakan form ini untuk mencatat semua kegiatan non-saklar seperti maintenance, sortasi, dll. Isi semua field dan tekan 'Simpan Laporan' untuk merekamnya ke Google Sheet.

3. Laporan

Dasbor interaktif untuk melihat data dari Google Sheet secara visual. Anda bisa melihat total durasi, jumlah aktivasi, dan log detail aktivitas saklar.

4. Penting: Pengaturan Awal

Sebelum menggunakan aplikasi, Anda harus memasukkan URL Web App dari Google Apps Script langsung ke dalam kode file HTML ini. Cari baris `const APPSCRIPT_URL = "..."` dan ganti dengan URL Anda.
